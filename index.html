Fondos en CSS

La propiedad background permite controlar el fondo de cualquier elemento HTML. Puedes usar colores, imágenes, degradados y combinarlos de muchas formas.

CSS ofrece varias propiedades relacionadas con el fondo. Las más importantes son:

  • background-color
  • background-image
  • background-size
  • background-position
  • background-repeat
  • background-attachment
  • background (shorthand)

1. background-color

Define un color sólido de fondo.

.caja {
    background-color: #3b82f6;
}
Color sólido

Valores posibles:

  • Nombre de color: red, blue...
  • Hexadecimal: #3b82f6
  • RGB / RGBA: rgb(59, 130, 246)
  • HSL: hsl(217, 91%, 60%)
  • transparent

2. background-image

Permite colocar una imagen de fondo.

.caja {
    background-image: url("imagen.jpg");
}
Imagen de fondo

También se puede combinar con un color usando un degradado semitransparente encima: 

.caja {
    background-image: 
        linear-gradient(rgba(59,130,246,0.6), rgba(139,92,246,0.6)),
        url("imagen.jpg");
}
Imagen + color

3. Degradados (Gradients)

Los degradados se aplican con background-image usando funciones especiales.

Linear Gradient

.caja {
    background-image: linear-gradient(135deg, #3b82f6, #8b5cf6);
}
Linear Gradient

Radial Gradient

.caja {
    background-image: radial-gradient(circle, #22d3ee, #3b82f6);
}
Radial Gradient

4. background-size

Controla el tamaño de la imagen de fondo.

Valor Descripción
cover La imagen cubre todo el elemento (puede recortarse)
contain La imagen se muestra completa (pueden quedar espacios)
100% 100% Estira la imagen al tamaño del elemento
200px 150px Tamaño fijo en píxeles 
.caja {
    background-image: url("imagen.jpg");
    background-size: cover;
}

5. background-position

Define la posición de la imagen dentro del elemento.

.caja {
    background-position: center;
    /* Otros valores: top, bottom, left, right, 50% 50%, 20px 40px */
}

Valores comunes:

  • center / center center
  • top left, bottom right...
  • 50% 50%
  • 20px 40px

6. background-repeat

Controla si la imagen se repite o no.

Valor Resultado
repeat Se repite en ambas direcciones (valor por defecto)
no-repeat No se repite
repeat-x Solo horizontal
repeat-y Solo vertical 
.caja {
    background-image: url("patron.png");
    background-repeat: repeat;
}
background-repeat: repeat
background-repeat: no-repeat

7. background-attachment

Define si el fondo se mueve al hacer scroll o permanece fijo.

  • scroll → el fondo se mueve con el contenido (por defecto)
  • fixed → el fondo queda fijo (efecto parallax)
  • local → el fondo se mueve con el contenido del elemento
.caja {
    background-image: url("imagen.jpg");
    background-attachment: fixed;
    background-size: cover;
}
background-attachment: fixed

8. Múltiples fondos

Puedes combinar varias imágenes o degradados separándolos por comas. La primera capa queda encima. 

.caja {
    background-image: 
        linear-gradient(rgba(15,23,42,0.5), rgba(15,23,42,0.5)),
        url("imagen.jpg");
    background-size: cover;
}
Múltiples capas

9. background (shorthand)

Puedes escribir todas las propiedades en una sola línea. 

.caja {
    background: #3b82f6 url("imagen.jpg") center / cover no-repeat fixed;
}

Orden recomendado:

  1. background-color
  2. background-image
  3. background-position
  4. / + background-size
  5. background-repeat
  6. background-attachment

Resumen rápido

Propiedad Para qué sirve
background-color Color sólido
background-image Imagen o degradado
background-size Tamaño de la imagen
background-position Posición de la imagen
background-repeat Repetición
background-attachment Comportamiento al hacer scroll
background Atajo de todas las anteriores
